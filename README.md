### 📂 Scripts Included

#### 🔹 Password Generator

Generates a random secure password using /dev/urandom.

#### 🔹 Host Reachability Script

Checks whether a hostname or IP is reachable using ping.

#### 🔹 Cleanup on Ctrl+C (trap example)

Shows how to handle interrupts using trap and SIGINT.

#### 🔹 Taking input from user

Shows how to handle user inputs

#### 🔹 Exit script

Shows how to exit process with exit code.

#### 🔹 File Check Script

Checks whether the file exists or not.
